Write a function called `findShortestElement` which takes one parameter:

- `words` - an array of words

The function should return the shortest string within the given array of words.

**Notes**:

- If there are ties, it should return the first element to appear.
- If the given array is empty, it should return an empty string.

**For Example:**

```
var output = findShortestElement(['a', 'two', 'three']);
```

```
console.log(output); // should print 'a'
```
